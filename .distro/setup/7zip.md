
# ====================================
# 7zip command
# ====================================
7z x archive.7z / распаковать в текущую директорию
7z x archive.7z -o./mydir / распаковать в определенную директорию 
7z e archive.7z / распаковать без сохранения структуры директорий 
7z a archive.7z myfile.txt / упаковать один файл
7z a archive myfile1.txt myfile2.txt myfile3.txt / упаковать несколько файлов
7z a archive.7z /path/to/mydir / упаковать директорию и ее содержимое
7z a archive.7z myfile123.txt / добавить файлы в существующий архив
7z l archive.7z / просмотр файлов в архиве
7z t archive.7z / протестировать целостность архива
